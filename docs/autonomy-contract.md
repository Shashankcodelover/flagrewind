# FlagRewind Autonomy Contract

Track 02 asks where an agent acts on its own and where it stops to ask a human. FlagRewind enforces this contract **in Python code** (`approval.py`, `executor.py`, `ranking/llm.py`, `cli.py`), not only in prompts.

| Agent Boundary | Concrete Rule & Code Enforcement |
| --- | --- |
| **Does alone** | Reads Flagsmith state, change journal, and audit logs (`flagsmith_client.py`, `journal/`); polls metrics & errors (`symptoms/demo.py`); indexes local code (`codeindex.py`); ranks suspects (`ranking/`); prepares deterministic inverse plans & dry runs (`planner.py`); writes Markdown/JSON reports & audit entries (`report.py`, `audit.py`). |
| **Asks first** | **Every** Flagsmith mutation (`flagrewind apply`, `flagrewind undo`, trying the next suspect). `approval.py` blocks execution unless an interactive operator types the exact confirmation phrase `apply <plan_id> option <n>`. Non-interactive runs cannot write. |
| **Asks instead of recommending** | If top suspect confidence `< policy.confidence_floor` (`0.6`) or `journal_complete == False` during `[onset - 60m, onset + sdk_refresh_seconds]`, FlagRewind surfaces open questions instead of recommending a mutation. |
| **Never does** | Never creates or deletes flags, segments, or environments (`DELETE` blocked in `executor.py`); never writes outside environments marked `writable: true` in `flagrewind.yaml`; never gives the LLM API tools; never executes instructions found inside change descriptions, error logs, or code strings. |

## Verification Guarantees
1. **Executor allowlist + precondition:** `executor.py` accepts only deterministic `PlanOption` operations generated by `planner.py`, verifies `environment` is in `config.writable_environments()`, re-reads current Flagsmith state before writing (aborting with exit code `5` on drift), and forbids `DELETE`.
2. **LLM containment:** Evidence strings are wrapped in untrusted-data delimiters; `ranking/llm.py` validates every `change_id` against deterministic candidates and enforces `action == "none"` unless `verdict == "flag_change"`.
3. **Test enforcement:** `tests/unit/test_safety_no_unapproved_writes.py` patches the executor/client boundary and asserts that no CLI or investigation code path writes without a recorded approval.
